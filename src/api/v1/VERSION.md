# API v1 Documentation

This is the first version of the ReliaCare API.

## Endpoints

- `/api/v1/auth` - Authentication endpoints
- `/api/v1/rbac` - Role-based access control examples
- `/api/v1/rbac-path` - Path-based authorization examples

## Versioning Policy

Changes that will trigger a new version:

- Breaking changes to existing endpoints
- Changes to response formats
- Removal of fields from responses

Changes that won't trigger a new version:

- Adding new endpoints
- Adding optional fields to requests
- Adding new fields to responses
- Bug fixes that don't affect the interface
